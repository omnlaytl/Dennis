# MyVault Web 密碼庫（個人用 Web App）

可以「加入主畫面」使用的離線密碼管理工具。不需要 Mac，不需要 Apple 開發者帳號，也不會過期。

- **Face ID 解鎖**：透過 iPhone 的通行密鑰（Passkey）實現，需要 iOS 18 以上
- **主密碼**：備用解鎖方式，也用來保護資料金鑰
- **加密**：整個密碼庫都以 AES-256-GCM 加密後才存入裝置，包括名稱、帳號、網址
- **匯入**：可直接匯入 Excel（.xlsx）或 CSV，自動辨識中文欄位名稱
- **備份**：加密備份檔可存到 Google 雲端硬碟，也能在 iOS 原生版 MyVault 還原
- **離線**：第一次開啟後，沒有網路也能使用
- **無第三方程式**：不載入任何外部套件、字型或分析工具

---

## 一、部署到網路上（只需做一次，約 10 分鐘）

Web App 必須放在 **HTTPS 網址**上，Face ID 和加密功能才能運作。以下兩種方式都免費，擇一即可。

> 網站上放的只有程式檔案。**您的密碼資料不會上傳**，永遠只加密存在您的 iPhone 裡。

### 方式 A：GitHub Pages

1. 到 <https://github.com> 註冊帳號，並**務必開啟兩步驟驗證**（Settings → Password and authentication）。
   原因：能修改網站程式的人，就有機會竄改程式來竊取密碼。
2. 右上角 + → **New repository**
   - Repository name：例如 `vault`
   - 選 **Public**（免費帳號的 GitHub Pages 需為公開儲存庫；公開的只有程式碼，不含您的資料）
   - 按 **Create repository**
3. 在新儲存庫頁面點 **uploading an existing file**，把本資料夾內的**所有檔案與 icons 資料夾**拖進去（`tests` 資料夾可以不用上傳），按 **Commit changes**。
4. 進入 **Settings → Pages**
   - Source 選 **Deploy from a branch**
   - Branch 選 **main**、資料夾選 **/(root)**，按 **Save**
5. 等 1 到 2 分鐘，頁面上方會顯示網址，例如：
   `https://您的帳號.github.io/vault/`

### 方式 B：Cloudflare Pages（可不公開程式碼）

1. 到 <https://dash.cloudflare.com> 註冊並開啟兩步驟驗證
2. 左側 **Workers & Pages → Create → Pages → Upload assets**
3. 輸入專案名稱，例如 `my-vault-xyz`，把整個資料夾拖進去，按 **Deploy**
4. 完成後會得到網址，例如 `https://my-vault-xyz.pages.dev`

### 重要：網址決定之後就不要再改

資料與 Face ID 通行密鑰都綁定在這個網址上。如果日後要換網址，請先在舊網址**匯出加密備份**，再到新網址還原。

## 二、安裝到 iPhone

1. 用 **Safari** 開啟您的網址（必須用 Safari，Chrome 等其他瀏覽器無法加入主畫面成為獨立 App）
2. 點下方 **分享按鈕** → **加入主畫面** → **新增**
3. 從主畫面開啟「密碼庫」
4. 設定主密碼（至少 10 個字元）
5. 出現「啟用 Face ID？」時點 **啟用 Face ID**，依照畫面完成驗證

> 注意：Safari 分頁中的資料和主畫面 App 的資料是**分開存放**的。請一律從主畫面圖示開啟，不要在 Safari 分頁中使用。

---

## 三、匯入您的 Excel

1. 把 Excel 檔（.xlsx）用 AirDrop 傳到 iPhone，或從 Google 雲端硬碟 App 下載到「檔案」
2. 密碼庫 → 左上角 **設定** → **從 Excel／CSV 匯入** → 選取檔案
3. 確認「欄位對應」是否正確 → 按右上角 **匯入**
4. **匯入後請刪除原始 Excel 檔**，包括 Google 雲端硬碟上的那一份（見下方說明）

支援的欄位名稱（不分大小寫）：

| App 欄位 | 可接受的 Excel 標題 |
|---|---|
| 主要名稱（必要） | 主要名稱、名稱、標題、項目、title、name |
| 使用者名稱 | 使用者名稱、使用者、用戶名、username |
| 帳號 | 帳號、帳戶、account、email、login |
| 密碼 | 密碼、password |
| 網址 | 網頁地址、網址、網站、url、website |
| 備註 | 備註、其他備註、附註、說明、notes |
| 分類 | 分類、類別、category |

其他對應不到的欄位會自動併入備註，不會遺失。

## 四、資料可以放在 Google 雲端硬碟嗎？

| 放在雲端硬碟的檔案 | 是否安全 | 說明 |
|---|---|---|
| **原始 Excel（明文）** | 不建議 | 任何能登入您 Google 帳號的人、或取得分享連結的人，都能看到所有密碼。匯入 App 後請刪除，並清空雲端硬碟的「垃圾桶」 |
| **加密備份檔（.myvault）** | 可以 | 檔案已用備份密碼加密，沒有備份密碼就無法讀取。很適合放在雲端硬碟作為異地備份 |

### 把加密備份存到 Google 雲端硬碟

1. iPhone 先安裝 **Google 雲端硬碟** App 並登入
2. 密碼庫 → 設定 → **匯出加密備份** → 設定備份密碼
3. 點 **儲存／分享檔案** → 選 **儲存到檔案** → 左上角選擇 **雲端硬碟** → 選資料夾 → 儲存
   （也可以在分享選單中直接點 Google 雲端硬碟 App）

### 從 Google 雲端硬碟還原

設定 → **從加密備份還原** → 在檔案選擇器中切換到「雲端硬碟」→ 選取 .myvault 檔 → 輸入備份密碼。

**建議每次新增或修改重要密碼後，就匯出一次備份。** 設定頁會顯示上次備份的時間。

## 五、日常使用

- **解鎖**：開啟後點「使用 Face ID 解鎖」；Face ID 無法使用時輸入主密碼
- **複製密碼**：點複製圖示，切換到其他 App 貼上。剪貼簿會在設定的時間後嘗試清除
  （瀏覽器限制：只有在密碼庫仍在前景時才能清除剪貼簿）
- **自動鎖定**：預設閒置 3 分鐘，或離開 App 時立即鎖定，可在設定中調整
  （若覺得每次切回來都要 Face ID 太頻繁，可改成「30 秒後鎖定」）
- **電腦使用**：電腦瀏覽器也能開啟同一個網址，但資料是各裝置分開的。要同步請用「匯出加密備份 → 在另一台裝置還原」

## 六、更新網站時

1. 修改檔案後，打開 `sw.js`，把第一行的版本號加一，例如 `myvault-v1.0.0` → `myvault-v1.0.1`
2. 上傳到 GitHub（或重新部署到 Cloudflare）
3. iPhone 開啟 App 兩次後就會套用新版本（第一次下載、第二次生效）

資料不受網站更新影響。

## 七、安全設計

```
主密碼 ──PBKDF2-SHA256（60 萬次）──→ 金鑰 A ─┐
                                             ├─ 各自加密同一把「資料金鑰」
Face ID ──Passkey PRF──HKDF──────────→ 金鑰 B ─┘
                                                    │
                       資料金鑰（AES-256，只在解鎖時存在記憶體）
                                                    │
                       整個密碼庫 ⇄ AES-256-GCM ⇄ IndexedDB（本機）
```

- 鎖定、閒置或離開 App 時，記憶體中的資料金鑰與明文資料會被清除
- 錯誤的主密碼無法解開資料金鑰；每次嘗試都需要約 0.5 到 1 秒的運算，可以減緩暴力破解
- 頁面設定了嚴格的內容安全政策（CSP），只允許載入同網站的程式
- 所有顯示的資料都以純文字處理，匯入的內容無法執行程式碼

### 與 iOS 原生版的差異

- Web App 的資料金鑰沒有 Secure Enclave 硬體保護，安全性比原生版低一級，但仍遠勝於把密碼放在 Excel 中
- 網站程式由 GitHub／Cloudflare 提供，因此**帳號安全很重要**，請務必開啟兩步驟驗證
- **刪除主畫面圖示會一併刪除資料**，請定期匯出加密備份

## 八、常見問題

**看不到「啟用 Face ID」？**
需要 iOS 18 以上，並在「設定 → Face ID 與密碼」中開啟 Face ID，以及在「設定 → Apple 帳號 → iCloud → 密碼」中開啟 iCloud 鑰匙圈。若仍無法使用，請改用主密碼解鎖，功能完全相同。

**忘記主密碼怎麼辦？**
若 Face ID 仍可使用：用 Face ID 解鎖 → 設定 → 變更主密碼。
若兩者都無法使用：只能從加密備份還原（需記得備份密碼）。沒有備份就無法救回資料，這是加密設計的必然結果。

**換新 iPhone？**
舊手機匯出加密備份 → 存到 Google 雲端硬碟 → 新手機加入主畫面、設定主密碼 → 從加密備份還原。

**停用 Face ID 後，iPhone 裡還留著通行密鑰？**
到 iPhone「設定 → 一般 → 自動填寫與密碼」或「密碼」App，搜尋網址後手動刪除即可。
